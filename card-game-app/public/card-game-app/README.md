# 魔法市場の商人たち(オンライン対戦版・最小プロトタイプ)

これは「オンライン対戦できるカードゲーム」の最初のバージョンです。まだ画面デザインはとてもシンプル(飾りなし)ですが、次のことがすでに全部サーバー側で動きます。

- ルーム作成・参加(4桁のルームID)
- ゲームマスター(ホスト)によるゲーム設定・ゲーム開始
- 手番の進行、山札からのドロー、マナの逓減回復
- カードを表向き/裏向きで出す(コスト支払い・不発判定・ライフ+1)
- カードNo.1〜13、破滅、豪運の効果(混沌は簡易版)
- 黒いカードの使用回数管理(浄化のコスト計算に反映)
- 全体チャット・個人チャット
- 降参・退室・観戦モードへの移行
- 勝敗判定(最後の生存者、または山札切れ時のライフ比較)

## 動かし方(自分のパソコンで試す場合)

1. [Node.js](https://nodejs.org/)(バージョン18以上)をインストールする
2. このフォルダをどこかに展開する
3. ターミナル(コマンドプロンプト)でこのフォルダに移動し、以下を実行する

```
npm install
npm start
```

4. ブラウザで `http://localhost:3000` を開く
5. 別のタブやスマホから同じURL(同じネットワーク内なら `http://自分のPCのIPアドレス:3000`)を開けば、複数人で遊べます

## インターネット上に公開する場合(誰とでも遊べるようにする)

自分のパソコンを常時起動しておかなくても遊べるように、無料枠のあるホスティングサービスにアップロードする方法があります。代表的なものに **Render**(https://render.com)があります。

### Renderでの手順(概要)

1. Renderのアカウントを作る(GitHubアカウントでログイン可能)
2. このフォルダの中身をGitHubリポジトリにアップロードする
3. Renderで「New Web Service」→ そのGitHubリポジトリを選択
4. Build Command:`npm install`、Start Command:`npm start` を設定
5. デプロイが完了すると、`https://(適当な名前).onrender.com` のようなURLが発行される
6. そのURLを友達に共有すれば、誰でもブラウザから参加できます

(GitHubの使い方やRenderの詳しい画面操作は、実際にその場面まで進んだら改めて手順をご案内します)

## 今のバージョンでできていないこと(今後の課題)

- 画面デザインが最低限(手書きラフで決めた見た目にはまだ近づけていません)
- No.13混沌の効果パターンは、これまで決めた内容を簡略化した状態です(一部の効果のみ実装)
- ルーム作成画面での「カード枚数設定」画面はまだUIがありません(内部的には対応済み)
- 手札交換(No.6取引)は「枚数・コストを揃える」の細かい調整をせず、単純に手札を丸ごと交換する簡易版です
- カードの挿し絵は未実装(文字のみ表示)
- 再接続時に手札などが正しく復元されるかは未検証です
