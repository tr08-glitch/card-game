# カード挿絵の入れ方

このフォルダ(`public/images/`)に、カードごとの画像ファイルを置いてください。
**ファイル名を下の表の通りにするだけで、自動的にそのカードの挿絵として表示されます。**

|---|---|
| No.1 探索 | `1.png` |
| No.2 治療 | `2.png` |
| No.3 強奪 | `3.png` |

| No.5 防御 | `5.png` |

| シークレット「豪運」 | `luck.png` |

## 条件

- 形式は **PNG** にしてください(`.png` という拡張子)。他の形式(jpgなど)を使いたい場合は教えてください、コード側を対応させます。
- 画像のサイズは正方形に近いもの(例: 512×512px)がバランスよく表示されます。多少縦横比が違っても自動で収まるように調整されるので、厳密でなくて大丈夫です。
- ファイル名は半角英数字のみ、上記の通り正確にしてください(大文字・小文字も区別されます)。

## 画像がない場合

まだ用意していないカードは、画像なしでもカード名などのテキストはそのまま表示されます(挿絵の部分だけ空欄/絵柄なしになります)。すべて揃っていなくても、用意できたものから順に置いていけます。

## 置き方(GitHub経由でアップロードしている場合)

1. GitHubの `card-game-app/public/images/` フォルダを開く(なければ「Add file」→「Upload files」で `images` という名前のフォルダごと作成されます)
2. 用意した画像ファイルをドラッグ&ドロップ
3. 「Commit changes」で保存すれば、Renderが自動で再デプロイします
